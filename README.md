# Terminal Quest

**Learn Linux command-line skills through interactive missions and hands-on practice.**

Terminal Quest is a browser-based learning game designed to help users explore Linux terminal commands through missions and challenges. It combines a terminal-inspired interface with a mission-based learning experience, making command-line practice more accessible and engaging.

**[Live Demo](https://terminal-quest.netlify.app/) · [Source Code](https://github.com/dvrone/terminal-quest)**

## Features

- **Interactive Terminal** — Practice entering Linux commands through a terminal-style interface.
- **Mission-Based Learning** — Complete missions in sequence and unlock new challenges.
- **Progress Tracking** — Track experience points, level progress, and achievements.
- **Browser-Based Experience** — Start learning directly in your browser without installing a desktop application.
- **Persistent Preferences** — Save supported settings in your browser.
- **Lightweight Architecture** — Built with standard web technologies without requiring a frontend framework.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

### Prerequisites

You only need a modern web browser to use the live application.

To run the project locally, install Git and a code editor of your choice.

### Installation

Clone the repository:

```bash
git clone https://github.com/dvrone/terminal-quest.git
```

Navigate to the project directory:

```bash
cd terminal-quest
```

### Run Locally

Open `index.html` in your browser, or start a local development server from the project directory:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## How to Use

1. Open the [live application](https://terminal-quest.netlify.app/).
2. Explore the interactive terminal interface.
3. Enter commands and work through the available missions.
4. Complete missions in order to unlock subsequent challenges.
5. Track your progress and achievements as you learn.

## Learning Goals

Terminal Quest aims to make command-line learning more interactive by encouraging users to practice commands, solve challenges, and build familiarity with terminal workflows.

It is intended as a learning aid for beginners who want to develop their Linux command-line skills through a browser-based experience.
